# 이진석 (Jinseok Lee)

Java/Spring 기반 업무 시스템과 앱 백엔드를 개발하고 있습니다.

2019년부터 신규 시스템 구축과 운영/유지보수를 함께 해왔습니다. 상담사 근무관리, 교육 신청/변경, 차량 정비 예약, 입장권 예약, 발권, 결제처럼 업무 규칙이 많은 기능을 서비스로 구현하고, 외부 시스템 연동과 운영 중 문제 개선을 맡아왔습니다.

## 기술

- **Backend**: Java, Spring Framework, 전자정부프레임워크, MyBatis
- **Database**: Oracle, MSSQL, MariaDB
- **Frontend**: Nexacro N24, JSP, JavaScript
- **DevOps**: GitLab, SVN, Jenkins, Tomcat, AWS(CodeDeploy, S3)
